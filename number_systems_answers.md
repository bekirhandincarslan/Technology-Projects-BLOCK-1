## 2. Adding and subtracting Binary Numbers

### Addition
- 1011 + 1101 = 11000
- 100110 + 101011 = 1010001
- 11101 + 10111 = 110100

### Subtraction
- 1101 - 1010 = 0011
- 10110 - 1001 = 01101
- 10001 - 1110 = 00011

## 3. Two's Complement

- 101010: invert to 010101, add 1 = 010110
- 110011: invert to 001100, add 1 = 001101
- 1001: invert to 0110, add 1 = 0111

## 4. Fixed Point Representation

- 12.75 (4 integer bits, 4 fractional bits): 1100.1100
- 5.125 (3 integer bits, 5 fractional bits): 101.00100
- 7.5 (4 integer bits, 4 fractional bits): 0111.1000

## 5. Limits of Binary Representation

- Largest unsigned 8-bit number: 255 (11111111)
- Largest signed 8-bit number (two's complement): 127 (01111111)
- Smallest signed 8-bit number (two's complement): -128 (10000000)
